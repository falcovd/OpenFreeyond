# Credits

OpenFreeyond is a small 3D place in the browser. This file lists the third-party assets that ship with it and the software it is built on. The OpenFreeyond source code is under the MIT licence (see LICENSE). Each asset keeps the licence given below. The same list is shown on the start page under "Credits".

The records come from `app/src/data/licences.js`, which is the source of truth and is checked by tests (`app/tests/licences.test.js`, `app/tests/credits.test.js`). Records marked "To be confirmed" still need the builder's check before a release.
