# Sun shadows Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Objects in the place cast shadows that follow the visible sun, so the shadows turn with the sky as it drifts.

**Architecture:** The sun is already one `DirectionalLight` inside the sky group, and the group turns slowly, so the light direction follows the visible sun. We turn on a shadow map for that light, fit its shadow camera to the place with a pure function, and flag objects as casters or receivers by their `userData.kind`. A build-time constant switches shadows off.

**Tech Stack:** three.js 0.170 via A-Frame 1.6, Vitest (jsdom), headless Chrome (puppeteer-core outside the repo) for the visual check.

Design: `docs/plans/2026-11-09-shadows-design.md` (approved). Read `CLAUDE.md` first. The app lives in `app/`; run every command from `app/`.

**Rules for every task:** `npm run lint`, `npm run format:check`, `npm test` and `npm run build` pass before the last commit of each task. `src/logic/` stays free of A-Frame and the DOM. Work on branch `shadows` (already checked out). End each commit message with the co-author trailer the session gives you. Nothing is stored or sent. No new asset files.

## Facts the tasks rely on (checked in the code)

- `app/src/world/builders/sky.js` `buildSky(THREE, assets, params)` creates the sun: `new THREE.DirectionalLight('#ffd9a0', 1.0)` at `params.sun * 100`, added to the sky group. The group's `userData.update` turns it by `SKY_DRIFT`. The light target is the default one at the origin, so the shadow camera follows the light as the group turns.
- `sky.json` sun vector `[-0.6291, 0.6278, -0.4585]`: elevation about 39 degrees. Shadows are about 1.2 times as long as the object is high.
- `app/src/world/buildWorld.js` builds the world group. Groups carry `userData.kind`: `tree`, `bush`, `hedge`, `fence`, `furniture`, `house`, `flower-bed`, `interior` (the interior group). Sky, ground and path have no `kind` yet.
- The character is an A-Frame entity outside the world group; `scene.js` sets its mesh with `el.setObject3D('mesh', ...)`.
- Interior models arrive later and are placed by `buildInterior().replace()` in `app/src/world/builders/interior.js`.
- A-Frame's `shadow` system only enables the renderer's shadow map when an A-Frame component asks for it. We use raw three objects, so `scene.js` must enable it itself.
- Existing test: `tests/buildWorld.test.js` expects exactly one directional light.

    expect(f.bottom).toBe(-f.top);
    expect(f.right).toBeGreaterThan(0);
    expect(f.near).toBeGreaterThan(0);

      const up = Math.abs(dir[1]) > 0.99 ? [1, 0, 0] : [0, 1, 0];

      const fwd = dir.map((c) => -c);

      const up2 = cross(right, fwd);

// If the frame-rate walk misses 30 fps, the builder decides what to drop first (see the checklist).
export const SHADOWS = 'on';

export const SHADOW_MAP_SIZE = 2048;
export const SHADOW_MAX_HEIGHT = 8; // metres: above the roof ridge (6.8) and the tallest tree (5)
export const SUN_DISTANCE = 100; // metres from the origin, as in sky.js

`app/src/logic/shadowFrustum.js`:

```js
// The orthographic shadow box of the sun light. The light looks at the origin and the sky group
// turns about the y axis through the origin, so a sphere around the origin that holds the whole
// place holds it for every azimuth and every sun height. No A-Frame, no DOM.
export function shadowFrustum({ bounds, maxHeight, distance }) {
  const radius =
    Math.hypot(
      Math.max(Math.abs(bounds.minX), Math.abs(bounds.maxX)),
      Math.max(Math.abs(bounds.minZ), Math.abs(bounds.maxZ)),
      maxHeight,
    ) * 1.02;
  return { left: -radius, right: radius, top: radius, bottom: -radius, near: Math.max(1, distance - radius), far: distance + radius };
}
```

**Step 3: Implement**

`app/src/world/builders/shadows.js`:

```js
import { SHADOWS } from '../shadowConfig.js';

// cast: throws a shadow. receive: has shadows drawn on it.
export const SHADOW_RULES = {
  tree: { cast: true, receive: true },
  bush: { cast: true, receive: true },
  hedge: { cast: true, receive: true },
  fence: { cast: true, receive: true },
  furniture: { cast: true, receive: true },
  house: { cast: true, receive: true },
  character: { cast: true, receive: true },
  // Flat things and the inside of the house only receive. The roof and walls already shade the rooms.
  'flower-bed': { cast: false, receive: true },
  interior: { cast: false, receive: true },
  ground: { cast: false, receive: true },
  path: { cast: false, receive: true },
  sky: { cast: false, receive: false },
};
const NONE = { cast: false, receive: false };

function kindOf(object, fallback) {
  for (let o = object; o; o = o.parent) if (o.userData?.kind) return o.userData.kind;
  return fallback;
}

// Sets castShadow and receiveShadow on every mesh under `root` by the kind of its nearest ancestor.
// See-through materials never cast (the window glass lets the sun in).
export function applyShadows(root, { enabled = SHADOWS === 'on', kind } = {}) {
  root.traverse((o) => {
    if (!o.isMesh) return;
    const rule = enabled ? (SHADOW_RULES[kindOf(o, kind)] ?? NONE) : NONE;
    const see = [].concat(o.material ?? []).some((m) => m?.transparent);
    o.castShadow = rule.cast && !see;
    o.receiveShadow = rule.receive;
  });
}
```

Tag the kinds: in `ground.js` set `mesh.userData.kind = 'ground'` in `buildGround` and `'path'` in `buildPath`. In `sky.js` `buildSky` set `group.userData.kind = 'sky'`.
